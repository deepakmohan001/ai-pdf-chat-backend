# AI PDF Chat Application

An AI-powered application that allows users to upload PDF documents and ask questions about their content.

## Technologies

### Backend
- Python
- FastAPI
- MongoDB
- OpenAI API

### AI and Machine Learning
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- PyPDF
- FAISS
- Embeddings
- RAG

### Frontend
- React
- Vite
- JavaScript
- CSS

## Backend Setup

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Configure environment variables using `.env.example` as a reference.
5. Run the application:

   `uvicorn main:app --reload`

## API Documentation

Visit `http://127.0.0.1:8000/docs` after starting the backend.
